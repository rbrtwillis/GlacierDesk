# GlacierDesk

A planned native macOS app for browsing, uploading, restoring, and downloading Amazon S3 objects, with a focus on S3 Glacier storage classes.

GlacierDesk is in the planning stage. See [PLAN.md](PLAN.md) for the proposed features, credential-security design, architecture, and milestones.
